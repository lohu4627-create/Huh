RADIANANO — BUILD APK WITHOUT ANDROID STUDIO

ZIP nay la goi MA NGUON + cau hinh build tu dong, khong phai APK.

CACH BUILD
1. Tao repository moi tren GitHub.
2. Dua NOI DUNG du an vao repository, giu nguyen cau truc:
   .github/workflows/build-apk.yml
   app/build.gradle.kts
   app/src/main/AndroidManifest.xml
   app/src/main/java/com/example/radianano/MainActivity.kt
   build.gradle.kts
   gradle.properties
   settings.gradle.kts
3. Mo tab Actions.
4. Chon "Build RadiaNano APK".
5. Bam "Run workflow" > "Run workflow".
6. Khi build xong, mo lan chay co dau tick xanh.
7. Trong Artifacts, tai "RadiaNano-APK".
8. Giai nen artifact va cai app-debug.apk.

QUAN TRONG
GitHub khong tu giai nen ZIP khi upload vao repository. Khong upload nguyen ZIP
vao muc Upload files. Can dua cac file va thu muc ben trong vao repository,
giu nguyen duong dan; dac biet la thu muc an .github.

Du lieu serial:
Arduino gui moi dong, baud 9600:
CPM:12
PULSE:345

GIOI HAN
- app-debug.apk la ban debug, khong phai ban Play Store.
- App hien thi du lieu Arduino gui, chua co firmware BPW34 hoan chinh.
- CPM khong tu dong bang µSv/h; can hieu chuan dau do.
- App khong noi truc tiep voi giao thuc rieng cua RadiaCode.
